性能回退检查

本轮比较“计算 pass 复用”开关。两个入口使用相同运行时与画质，均开启阴影缓存、不限帧，保持 owner 调度。

实验尚未达到桌面端性能，也未确认改善移动手感。静止低帧有提升，移动收益很小，最坏 GPU 完成延迟有所增加。请特别留意转向顿挫、阴影跳变、拖尾或缺失。
